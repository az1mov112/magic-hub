# Как установить Magic Hub

Приложение не из App Store и без платной подписи Apple, поэтому macOS при первом запуске его не узнаёт. Это нормально: нужно один раз разрешить запуск.

Подходит для macOS 15 Sequoia и новее, на Mac с Apple Silicon (M1 и новее) и на Intel.

## 1. Скачать

1. Откройте https://github.com/az1mov112/magic-hub/releases.
2. В свежей сборке (`nightly`) скачайте `MagicHub.zip`.
3. Распакуйте архив двойным кликом и перетащите **Magic Hub** в папку **Программы**.

## 2. Разрешить запуск

1. Откройте Magic Hub двойным кликом. macOS скажет, что не может проверить приложение. Нажмите **Готово**.
2. Откройте  → **Системные настройки** → **Конфиденциальность и безопасность**.
3. Пролистайте вниз до строки про Magic Hub и нажмите **Всё равно открыть**, затем введите пароль.

Можно и через Терминал, одной командой:

```
xattr -dr com.apple.quarantine "/Applications/Magic Hub.app"
```

## 3. Первый запуск

- Значка в Dock нет. Приложение живёт в чёлке вверху по центру экрана и в меню-баре справа (сердечко и цифры).
- Наведите курсор на чёлку, и откроется панель. В настройках можно поменять наведение на клик.
- Все разрешения можно выдать разом: Настройки → «Разрешения» → «Запросить все». Что и зачем:
  - **универсальный доступ** — свой индикатор громкости и яркости в чёлке вместо системного;
  - **вставка из других приложений** — для истории буфера;
  - **календарь** — для вкладки «Календарь» в режиме «Календарь Mac»;
  - **связка ключей** — только для лимитов Claude на вкладке «ИИ-агенты»; нажмите «Всегда разрешать»;
  - **пароль администратора** — только если включите «Работать с закрытой крышкой» или управление вентиляторами. Пароль спрашивается один раз.

## Обновление

Когда выйдет новая версия, из чёлки выедет уведомление, а в шапке панели появится кнопка «Обновить». Нажмите её: Magic Hub сам скачает новую версию, заменит себя и перезапустится. Проверить вручную можно так: сердечко в меню-баре → «Проверить обновления».

Все сборки подписаны одним и тем же сертификатом, поэтому после обновления разрешения macOS сохраняются.

## Удаление

1. Выйдите из приложения: сердечко в меню-баре → «Выйти».
2. Удалите приложение из «Программ».
3. Удалите его данные — папку `~/Library/Application Support/MagicHub`.
4. Если ставили помощника для закрытой крышки или вентиляторов, удалите его кнопкой в настройках (раздел «Не спать») до удаления приложения.
