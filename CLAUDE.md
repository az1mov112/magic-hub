# Magic Hub — заметки для Claude

Родное приложение для macOS на Swift/SwiftUI: панель в чёлке (вырезе экрана) и значок в меню-баре.
Распространяется вне App Store. Описание для людей — README.md, техзадание — docs/SPEC.md,
мониторинг ИИ-ассистента — docs/JARVIS_ARCHITECTURE.md.

## Общение
- Отвечать по-русски. Код, команды, пути и названия файлов — по-английски.
- Тексты интерфейса и комментарии в коде — по-русски, как во всём проекте.

## Правила репозитория (публичный!)
- Никаких токенов, ключей, паролей, личной переписки, логов и личных данных в коммитах.
- Пароль от сертификата подписи не коммитить никогда: он только в секрете `MACOS_CERT_PASSWORD`.
- Пути и настройки не хардкодить — определять автоматически или задавать в приложении.
- Историю веток не переписывать (без force-push), если об этом прямо не попросили.
- Pull request не создавать, пока не попросят.

## Сборка и выпуск
- Локально (нужен Xcode 16+): `./scripts/bundle.sh` → `build/Magic Hub.app` и `build/MagicHub.zip`.
- Минимум macOS 15, универсальная сборка (Apple Silicon + Intel).
- GitHub Actions (`.github/workflows/build.yml`) собирает только пуши в ветки `claude/**`
  (и ручной запуск). Изменения только в `docs/`, `*.md`, `scripts/promo/` сборку не запускают.
- Номер сборки = номер запуска + 13, версия `0.1.<сборка>`. Готовая сборка публикуется в релиз
  `nightly`, откуда её забирает встроенное обновление (Настройки → Обновления).
- Без секрета `MACOS_CERT_PASSWORD` сборка подписывается ad-hoc и не публикуется — иначе у всех
  сбросятся выданные разрешения macOS. Сертификат: `certs/magichub-signing.p12`.
- `main` — витрина (README на странице GitHub); рабочая ветка — `claude/jarvis-monitoring-bk439e`.

## Устройство кода
| Путь | Что там |
|---|---|
| `Sources/MagicHub/App` | запуск, значок в меню-баре |
| `Sources/MagicHub/Core` | `AppModel` (вкладки, уведомления в чёлке), `Prefs`, тема, утилиты |
| `Sources/MagicHub/Notch` | окно-чёлка, наведение, режимы (open > layout > drop > hud > notif > live > idle) |
| `Sources/MagicHub/Features/*` | вкладки и сервисы |
| `Sources/MediaRemoteBridge` | мост «Сейчас играет» |

## Как отлаживать у пользователя
Пользователь присылает отчёт: Настройки → в самом низу «Диагностика» → «Скопировать».
В нём нет переписки и токенов — только технические сведения по разделам ([Джарвис], [Notion],
[Уведомления Mac]). Если чего-то не хватает для разбора — добавить строку в `diagnostics()`
нужного сервиса и выпустить сборку.

## Уведомления Mac (Features/Notifications)
- Чужие уведомления перехватить нельзя: читаем базу Центра уведомлений
  `~/Library/Group Containers/group.com.apple.usernoted/db2/db` (SQLite, только чтение, нужен
  «Полный доступ к диску»). Слежение за `db-wal` + проверка 4 раза в секунду (экономно — раз в секунду).
- Пока уведомления включены, App Nap отключён (`ProcessInfo.beginActivity`) — без этого macOS
  придерживает таймеры на секунды.
- Новые записи узнаём по номеру и по uuid: номер macOS может выдать повторно.
- Фокус: активные — `~/Library/DoNotDisturb/DB/Assertions.json`; список приложений фокуса ищется
  эвристикой во всех JSON этой папки (формат Apple не документирован). Неизвестно — показываем.
- Звука у уведомлений в чёлке нет намеренно: родной звук играет сама macOS.

## Открытые вопросы
- Проверить по диагностике, что разбор списка приложений фокуса находит нужные приложения.
- Нагрузка процессора: в диагностике есть средняя с запуска — сравнить с текущей.
- Календарь Notion: в последней диагностике 0 строк и «обновлено: ни разу» — проверить.
