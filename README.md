# Magic Hub

Неофициальное приложение для macOS (не из App Store): панель-чёлка с полезными функциями, цифры системы в меню-баре и мониторинг Telegram-ассистента «Джарвис».

- **Установить:** [docs/INSTALL.md](docs/INSTALL.md). Свежая сборка — в [Releases → nightly](https://github.com/az1mov112/magic-hub/releases).
- **Что умеет:** [docs/SPEC.md](docs/SPEC.md).
- **Устройство Джарвиса** (для функции мониторинга): [docs/JARVIS_ARCHITECTURE.md](docs/JARVIS_ARCHITECTURE.md).

## Функции

- **Чёлка:** открывается наведением или кликом, два стиля (под вырез и своя на Mac без выреза), живые индикаторы, уведомления.
- **Вкладки:** музыка из любого источника, полка скриншотов, история буфера, заготовки, задачи из Notion или Календарь Mac, перевод текста и фото, заметки, валюта, телесуфлёр, калькулятор, ИИ-агенты (Джарвис и Claude), «Не спать» (в том числе с закрытой крышкой).
- **Меню-бар:** температура и нагрузка CPU, память, батарея, вентиляторы; подробности по клику.

## Сборка из исходников

Нужен Mac с Xcode 16 или новее:

```
./scripts/bundle.sh        # → build/Magic Hub.app и build/MagicHub.zip
```

Структура:

| Путь | Что там |
|---|---|
| `Sources/MagicHub/App` | запуск, значок в меню-баре |
| `Sources/MagicHub/Core` | настройки, тема, общие элементы, утилиты |
| `Sources/MagicHub/Notch` | окно-чёлка, наведение, анимации, панель |
| `Sources/MagicHub/Features/*` | вкладки и сервисы |
| `Sources/MediaRemoteBridge` | мост «Сейчас играет» (загружается системным perl) |

## Правила репозитория

- Никаких токенов, ключей, личной переписки и логов в коммитах (см. `.gitignore`).
- Пути и настройки не захардкожены: автоопределение или настройки приложения, чтобы работало у друзей.
