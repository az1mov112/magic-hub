# Magic Hub

Неофициальное приложение для macOS (не из App Store) — набор полезных функций в одном окне.

## Функции
- **Мониторинг Джарвиса** — состояние Telegram-ассистента на Claude Code: жив ли он, занят ли, скорость ответов, размер контекста, ошибки и лимиты, качество интернета; перезапуск по кнопке. Подробности устройства — [docs/JARVIS_ARCHITECTURE.md](docs/JARVIS_ARCHITECTURE.md).
- Остальные функции — будут описаны.

## Правила репозитория
- Никаких токенов, ключей, личной переписки и логов в коммитах (см. `.gitignore`).
- Пути и настройки — не захардкожены: автоопределение или настройки приложения, чтобы работало у друзей.
